# Packed chromosome simulation qualification

The bounded qualification compares the committed byte oracles with the
experimental `gbits` packed path using exact equality only.  It covers a
phase-asymmetric HAPNEST reference panel, founder segment audit equality,
children, grandchildren, a later founder, full siblings, paternal and maternal
half siblings, fixed zero/one/multiple and marker-equal crossovers, and three
distinguishable chromosome labels in forward and reverse orchestration.

Acceptance requires zero H1, H2, genotype, event-record, metadata, and
Mendelian mismatches; fixed-seed, output-option, operational-batch,
chromosome-order, and R-global-RNG invariance; changed-seed divergence; and
successful raw regression suites.  Memory measurements report biological
payloads and event objects separately, not whole-genome retention.

## Results

The phase-asymmetric founder comparison reported `(H1, H2, genotype, event)`
mismatches `(0, 0, 0, 0)`.  The multigenerational pedigree comparison reported
the same tuple `(0, 0, 0, 0)` and zero independently checked Mendelian
inconsistencies.  Sample IDs, variant IDs, chromosome assignment, variant map,
and pedigree alignment were identical.  Forward and reverse orchestration of
`chrZ`, `01`, and `CHR1` produced zero mismatches for both founder and pedigree
outputs.  Fixed seeds, individual batches, output options, and the R global RNG
were invariant; informative changed seeds diverged.

For 128 individuals by 129 markers on one chromosome, measured biological
payload bytes were:

| Payload | Byte encoded | Packed |
|---|---:|---:|
| reference H1 + H2 | 33,024 | 4,128 |
| generated H1 + H2 | 33,024 | 4,128 |

This is exactly an eightfold reduction because 128 needs no partial-word
padding.  The compact founder plan contained 943 segment records; its R data
frame, including R object overhead, measured 77,952 bytes.  Native founder
materialization used no additional variable-size temporary buffer.  Optional
decoded genotype counts would require 16,512 bytes and the default allocated
zero such bytes.

The smaller pedigree parity fixture had 10 individuals and 25 markers.  Its
founder byte/packed payloads were 250/400 bytes, generated byte/packed payloads
were 500/400 bytes, crossover audit object was 10,480 bytes, maximum temporary
crossover-boundary storage was 136 bytes, and optional decoded genotypes were
250 bytes.  The small packed payload includes one complete 64-bit word per
marker and therefore is not expected to approach eightfold reduction.

The final focused totals were 12/12 `gbits` CTest programs, 71/71 packed R
expectations, 140/140 committed founder expectations, 80/80 committed meiosis
expectations, 51/51 existing `gsim()` expectations, and 102/102 existing
pedigree/record expectations.  Isolated installs and final diff checks are part
of the handoff gate.
